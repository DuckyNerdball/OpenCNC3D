OpenCNC3D -- macOS
=================

START HERE
----------
Requires macOS 14 (Sonoma) or newer. The same download runs natively on
Apple Silicon (M-series) and Intel Macs. Apple Silicon does not need Rosetta.
Both Dawn3D and RA3D are supported.

Open OpenCNC3D.app to start the launcher. Do not double-click the plain
opencnc3d, cnc_eyes or opencnc3d-launcher files beside it. Keep the app and all
its neighboring files together; use a Dock shortcut or Finder alias instead
of moving the app out of its folder.


WHICH DOWNLOAD TO CHOOSE
-----------------------
OpenCNC3D Complete: the launcher with Dawn3D included.
RA3D Complete: the launcher with Red Alert 3D included.
OpenCNC3D Installer: the launcher only; choose Add Game after opening it.
OpenCNC3D Binaries / RA3D Binaries: updates for a matching complete installation.
A Binaries archive has no game data or artwork and cannot run on its own.

The Complete installers include their game offline. Movies and music are
optional. The empty Installer downloads no game during installation.


INSTALLING A .PKG
-----------------
1. Open the downloaded macOS .pkg and follow Installer.
2. Complete installers offer optional Movies and Music in Customize.
3. In Finder choose Go -> Home, then open Applications -> OpenCNC3D.
4. Open OpenCNC3D.app there.

The destination is ~/Applications/OpenCNC3D, inside YOUR home folder.
It is separate from the Mac's main Applications folder (/Applications, the
one in the Finder sidebar), so look in your home folder, or type OpenCNC3D
into Spotlight. Existing saves,
settings and custom maps are preserved. Installation does not start a game.


OPENING A FULL .ZIP DOWNLOAD
---------------------------
Extract the whole archive, then open OpenCNC3D.app inside the extracted folder.
Keep all the extracted files together. A full ZIP does not run Apple's Installer
and does not automatically put the game in Applications.

If the filename says Binaries, it is an update rather than a full download.
Apply it over a complete installation of the matching game and version;
choose a Complete installer for a first installation.


CHOOSING A GAME, MOVIES AND MUSIC
-------------------------------
The launcher shows installed games. Select Dawn3D or RA3D and use its play
button. Add Game opens the game browser; choose a game and its optional Movies
and Music downloads. Either game can be installed independently.

The gear manages content for the selected game. It also lets you retry an
unfinished optional download. The other game's content and your saves/settings
stay separate. A game can be played without optional movies or music.


IF macOS BLOCKS THE DOWNLOAD
---------------------------
The installers and the app are not signed with an Apple Developer ID and are
not notarized by Apple yet. The first time you open a download, macOS says it
could not verify that it is free of malware, and offers only Done and Move to
Trash. That is the signing, not a fault in the download and not a CPU problem.
To open it anyway:

1. Click Done (not Move to Trash).
2. Open System Settings -> Privacy & Security and scroll down to Security.
   It names the file macOS just blocked. Click Open Anyway and confirm with
   your Mac's password or Touch ID.
3. Open the file again and click Open Anyway (or Open) in the box that follows.

The Open Anyway button stays for about an hour after the blocked attempt; if
it is gone, open the file once more and go back. On macOS 14 (Sonoma) you can
instead Control-click the file in the Finder and choose Open.

Or, in Terminal, clear the download's quarantine mark (use the file's real
name and folder):

  xattr -d com.apple.quarantine ~/Downloads/OpenCNC3DInstaller-macos-vX.Y.Z.pkg

Apple's explanation: https://support.apple.com/102445

A warning that specifically identifies malware, or says a file is damaged,
needs investigation. Keep the exact warning and download filename for a report.


CONTROLS AND VISUALS
-------------------
LEFT click selects. With a selection, clicking ground moves and clicking an
enemy attacks. LEFT drag selects a group; SHIFT adds to the selection.
RIGHT click cancels the current action or deselects.
CTRL + LEFT forces an attack. ALT + LEFT forces movement.
S stops; X scatters; G or Z guards. M toggles the radar.
ESC opens the pause/options menu.

Use Visuals from the main menu or in-mission options to choose the picture.
Dawn3D offers Classic, N64 and Enhanced. RA3D offers Classic and Enhanced.
Your saved settings can change which mode starts. Menus use the current
Enhanced interface in every mission graphics mode.


IF IT STILL DOES NOT START
-------------------------
In Apple menu -> About This Mac, check the macOS version. Releases require
macOS 14 or newer even on an Apple Silicon Mac. Then confirm that you opened
OpenCNC3D.app, kept its folder together and used a full download for a new install.

Include the download filename/version, Mac model/chip, macOS version and exact
error text in a bug report. If the launcher opens, also say which game you
selected. The build number is shown in the game menu. These details distinguish
installation, signing, missing game data and game-start failures.


THE GAME'S LOG
--------------
Send the game's log with a bug report. A game started from the Finder or the
launcher writes it to this folder (Finder -> Go -> Go to Folder):

  ~/Library/Application Support/OpenCNC3D/

opencnc3d-log.txt is the session that is running or ran last. Starting the game
again does not erase it: the session before is kept as opencnc3d-log-previous.txt,
and a session that crashed is also kept as opencnc3d-crash-<date>-<time>.txt (the
newest five). After a crash the game says so on its next start and names the
file to send. macOS also keeps its own crash report for the game in Console ->
Crash Reports.
